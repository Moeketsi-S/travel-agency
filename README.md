# Sweet Crumbs Bakery Website

## Project Description

This project is a professional website developed for Sweet Crumbs Bakery as part of the Web Development PoE.

The website aims to provide the bakery with an online presence where customers can learn about the organisation, view its products and services, and contact the business.

## Organisation

**Sweet Crumbs Bakery**

**Type:** Small Business  
**Industry:** Bakery / Food Services  
**Location:** Johannesburg, South Africa

## Project Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Visual Studio Code

## Project Structure

- `index.html` – Homepage
- `css/` – Stylesheets
- `js/` – JavaScript files
- `images/` – Website images and other visual assets
